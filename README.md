# كلمة تشدّ حيلك 📓

تطبيق ويب بيطلّع كلام حماسي لطالب تالتة ثانوي: مذاكرة، عبادة، أهل، ثقة، مع آيات وأحاديث وأدعية.

## المميزات
- ٥٠٬٦٢٥ جملة في كل قسم، و٥٤ آية و١٦ حديث و١٣ دعاء.
- أي جملة مش بتظهر أكتر من ٥ مرات.
- "اكتب حالتك": اكتب تعبان / خايف / زهقان... وحماس يرد بالنوع المناسب.
- ⭐ مفضلة ونسخ.
- صوت تفاعلي مع الضغط والكتابة وحركة الماوس (مولّد بالكود) وزرار كتم.
- شغّال بدون نت بعد أول زيارة، وينفع يتثبّت كتطبيق على الموبايل.

## الملفات (ارفعها كلها في نفس الفولدر)
`index.html` `sw.js` `manifest.webmanifest` `icon-192.png` `icon-512.png`

## النشر على GitHub Pages
1. ريبو جديد ← Add file ← Upload files ← ارفع الملفات.
2. Settings ← Pages ← Branch: `main` / `(root)` ← Save.
3. افتح اللينك مرة واحدة وإنت أونلاين، وبعدها هيشتغل بدون نت.
